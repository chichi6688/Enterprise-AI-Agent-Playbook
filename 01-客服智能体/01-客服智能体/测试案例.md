# 客服 Agent 测试案例


## 测试目的

验证 AI Agent 在不同客户咨询场景下的回答准确性。


---

# Case 1：物流查询


## 用户输入

我的订单什么时候可以收到？


## 预期结果

Agent 应根据物流政策回答：

美国地区订单预计7-15个工作日送达。


## 验证结果

通过。


---

# Case 2：退款咨询


## 用户输入

我收到商品后不满意，可以退款吗？


## 预期结果

Agent 根据退款规则回答：

满足条件可以申请退款。


## 验证结果

通过。


---

# Case 3：未知问题测试


## 用户输入

你们公司有没有提供私人定制服务？


## 预期结果

如果知识库没有相关信息：

Agent 不应该编造答案。

应该回复：

"暂时无法确认该信息，建议联系人工客服。"


## 验证结果

通过。


---

# 优化记录


第一次测试：

问题：

部分回答过于宽泛。


优化：

增加 Prompt 约束：

- 必须引用知识库
- 不确定信息转人工


第二次测试：

回答准确度提升。
