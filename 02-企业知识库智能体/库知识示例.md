# 企业知识库文档示例 (Knowledge Base)

在 Dify 的知识库中，我们上传了以下模拟的企业文档以供 Agent 检索：

## 文档 1: 产品说明书 (Product A Documentation)
* **支持功能 (Features)**：
  - 用户权限管理 (User Management)
  - 数据分析看板 (Analytics Dashboard)
  - API 接口集成 (API Integration)
* **产品限制 (Limitations)**：
  - 单租户最大支持用户数：1000 人。

## 文档 2: HR 规章制度 (HR Policy)
* **远程办公政策 (Remote Work Policy)**：
  - 员工每周最多可申请 3 天远程办公。
  - 必须提前在系统中提交申请，并获得直属经理 (Manager) 审批同意。
* **报销流程**：
  - 员工提交发票 → 财务审核 → 5个工作日内打款。

## 文档 3: 销售资料 (Sales Materials)
* **产品定价 (Pricing)**：
  - 企业版套餐 (Enterprise Plan)：$999/月。
  - 套餐包含：无限制用户数 (Unlimited users)、专属优先支持 (Priority support)。
