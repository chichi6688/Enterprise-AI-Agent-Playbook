# 🏢 企业知识库智能助手 (Enterprise Knowledge Assistant)

## 项目定位
本项目旨在帮助企业员工通过自然语言快速查询内部知识（如产品手册、HR制度、销售资料等），从而大幅降低信息检索时间，提高跨部门协作效率。这是一个面向企业内部的典型 AI FDE（前瞻部署工程师）落地案例。

## 核心能力
* **基于 RAG 的精准问答**：结合企业私有数据源，提供准确、带引用来源的答案。
* **多文档统一检索**：打破 PDF、Word、Notion 等不同载体的信息孤岛。
* **严谨的边界控制**：对知识库外的问题拒绝回答，避免 AI 幻觉引发的内部误导。

## 技术栈
* **应用编排**：Dify
* **大语言模型**：Gemini
* **核心技术**：RAG (Retrieval-Augmented Generation), 向量检索
